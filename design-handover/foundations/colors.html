Color

Dark-first, near-black ground, white text, one cool accent. Color is used sparingly and never as a coat of paint. Always reference the token, never the raw hex.

--bg
#0d0d0d
Page background, solid card fills.
--fg
#ffffff
Primary text.
--fg-mute
rgba(255,255,255,.7)
Secondary text, body copy inside sections.
--fg-dim
rgba(255,255,255,.5)
Tertiary: captions, meta, categories. Never primary reading copy.
--line
rgba(255,255,255,.15)
Hairline borders, dividers, table rules.
--accent
#a8c7ff · periwinkle
Hero headline, links on hover, active states, primary buttons.

Rules

  • The accent is a cool periwinkle. Never swap it for a warm or brand-y color, and never add a second accent.
  • The green / blue / sunset gradient panels are art, not UI tokens. Don't reuse them for buttons, cards, or text.
  • Don't hardcode a color that already has a token.
  • Don't use --fg-dim for primary reading copy — contrast fails.
