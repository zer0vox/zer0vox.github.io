Project panels

The work section is a stack of sticky full-viewport panels that slide over one another as you scroll. Each one is a photograph under a flat black scrim, numbered left, named right. No thumbnails, no grid, no captions.

Shown at 300px tall. Live: position: sticky; top: 0; height: 100vh; min-height: 640px; isolation: isolate, background is linear-gradient(rgba(0,0,0,.38–.42) ×2), url(photo) center/cover no-repeat. The gradients above stand in for the photographs (dna.png, vision.png, logic-spiral.jpg, limitless.JPG).

Type & placement

  • Number — left: 24px, vertically centred, weight 600, clamp(72px, 12vw, 200px), tracking -.05em, line-height .85, text-shadow: 0 2px 24px rgba(0,0,0,.55).
  • Name — right: 24px, vertically centred, right-aligned, weight 600, clamp(40px, 6vw, 96px), tracking -.04em, line-height .95, text-shadow: 0 2px 16px rgba(0,0,0,.55).
  • Reveal — both animate once on scroll-in: number from x: -40, name from x: +40 (delay .08s), .7s [0.22,0.7,0.18,1], viewport: {once:true, amount:.5}. The animated element is an inner span so it never fights the parent’s translateY(-50%) centring.
  • Placeholder tag — while artwork is missing, centre a dashed mono chip: rgba(0,0,0,.45) fill, 1px dashed rgba(255,255,255,.25), radius 6px, 11px mono, tracking .16em, uppercase.

Rules

  • These gradients are art. Never reuse them for buttons, cards, text or any UI surface — that is what --accent is for.
  • Photographs always sit under a flat black scrim at .38–.42 so white 600-weight type stays legible without a box behind it.
  • Panels are unlinked in the current build. If they become links, the whole panel is the target — do not add a button.
  • Extra decoration (the p2 dot grid + gold wave, the p1 script word) is per-panel and optional. Keep at most one such device per panel.
