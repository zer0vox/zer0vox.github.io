Layer stack

0.bgSolid #000 — darker than --bg, so the hero reads as a separate stage.
0.hero-patternThe line-art SVG. Breathes on two desynced loops: heroFlameFlicker 13s (opacity .94–1 plus one composed filter chain carrying brightness, a warm ember drop-shadow and a faint hue drift) and heroFlameRise 22s (translateY -0.3%, scaleY 1.006, origin 50% 100%).
0.hero-iridescenceTwo counter-rotating conic + linear gradient layers (26s / 18s), blur(40px) saturate(150%), mix-blend-mode: screen so the sheen catches only the bright strokes. A radial mask keeps it off the centre and the edges — a ring, not a wash.
0.hero-glareCursor-following faded-sun bloom: gold core → amber → periwinkle → violet → teal rim. Driven by inherited --gx/--gy/--gi written by a rAF loop; alphas scale with --gi so it whispers at rest. Plus a two-offset chromatic whisper and lifted blacks (::before) and film grain (::after).
1.copyGrid 1fr auto, aligned to the baseline, bottom: 36px, max-width: var(--max). Stacks to one column at 810px with a 12px gap.

anim.line .innerEach line is a clipped .line wrapping an .inner that rises from translateY(110%) + opacity 0 over 1s cubic-bezier(.22,.7,.18,1). Delays .05s / .20s / .34s. Break the copy into three lines by hand.
cue.scroll18px weight 500, the literal string (Scroll) with the parentheses dimmed to --fg-dim. That bracket treatment is a recurring device — reuse it for other inline cues.

Rules

  • The hero has no CTA button. The scroll cue is the only affordance.
  • Never scale the headline up to compete with the artwork. If it needs more presence, give it more space.
  • The glare must read the live --gx/--gy/--gi, never re-declare them — re-declaring shadows the rAF values and freezes the effect invisible.
  • Every circle radius in the glare gradients is a length (vmax); percentages are only valid on ellipse.
  • Under reduced motion: flicker and drift stop, and the glare becomes a fixed centred bloom at 50%/42%. Nothing is hidden.
