Sections

Every section is a translucent near-black band over the fixed Fibonacci background, with its content in a .wrap. The alpha is the only thing that changes between them.

Index

Body copy inside a section is --fg-mute at line-height 1.5, capped at 52ch. The heading takes --display.

<section class="my-section">
  <div class="wrap">
    <h2>/* --display */</h2>
  </div>
</section>

.my-section {
  background: rgba(13, 13, 13, .5);
  padding-block: var(--section-y);
  position: relative;
  z-index: 1;
}

Rules

  • Section alphas run .45 → .70 from the CTA down to the footer. Keep new sections inside that range so the background reads continuously.
  • Every section needs position: relative and a z-index of at least 1, or the fixed background paints over it.
  • One idea per section. There is no two-column body copy anywhere in this system.
  • Section headings use --display; only the CTA and the footer wordmark earn --huge.
