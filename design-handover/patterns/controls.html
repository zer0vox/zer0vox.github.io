Controls & rows

Buttons, inputs, cards and index rows, drawn to the system so new surfaces have somewhere to start.

Status — spec, not shipped
None of these components exist in the current codebase. The live page (nav, hero, four project panels, statement, CTA, footer) contains no buttons, inputs, cards or tables at all. These specs are carried forward from an earlier build of the site — treat them as the agreed direction for when such a component is needed, and re-verify against src/index.css once one actually ships.

Rules

  • Primary buttons are the only place a solid accent fill appears. One per view.
  • Radii: 4px controls, 6px chips, 8px cards and tables, 999px pills. Media thumbs stay square.
  • Every interactive element keeps a visible --accent focus outline and a tap target of at least ~40px.
  • Dynamic updates (filtering a grid, a form result) need a visually-hidden live region announcing the change.
  • No red, green or amber status colors exist. If a semantic state is genuinely required, propose it before shipping it.
